We're excited to launch **Scout Beta**.

### What's included

- AI-powered job application agent
- Automated application form filling
- Resume analysis and scoring
- Application tracking
- Intelligent fallbacks when applications cannot be completed

Scout is currently in beta and actively improving. If an application can't be completed, you'll receive a clear explanation and won't be charged for unsuccessful runs. The good news is we're actively improving Scout's reliability across more job platforms.

More updates coming soon.
